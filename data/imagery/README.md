# Imagery

This directory contains astronomical image products used throughout the Cosmic Intelligence Lab.

## Organization

- **raw/** — Original downloaded imagery.
- **processed/** — Images generated through processing pipelines.
- **hst/** — Hubble Space Telescope images and FITS files.
- **jwst/** — James Webb Space Telescope images.
- **alma/** — ALMA continuum and spectral image products.
- **derived/** — Figures, plots, overlays, and AI-generated visualizations.

Notebook-generated figures should be moved here when they become useful data products.
