# JADES DR5 Structure

The official JADES DR5 FITS catalog is organized as multiple related
extensions sharing the same source IDs.

Important extensions:

- KRON
  - Source ID
  - RA / DEC
  - Kron photometry
  - Basic morphology

- PHOTOZ
  - Photometric redshifts
  - Spectroscopic redshifts
  - Redshift probability distributions

- SIZE
  - Structural measurements

- FLAG
  - Quality flags
