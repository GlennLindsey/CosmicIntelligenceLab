# Cosmic Intelligence Lab

An AI-assisted astronomical research project using local language models,
astronomical databases, Python, JupyterLab, and automated research agents.

## Current Architecture

- **Nemotron 3 Nano 4B** — local agent model
- **Ollama** — local model runtime
- **SIMBAD** — astronomical object information
- **MAST** — archival astronomical observations
- **VS Code** — software development
- **JupyterLab** — scientific exploration
- **RTX 3050** — local GPU acceleration

## Current Agent

The Cosmic AI agent can:

1. Query SIMBAD for an astronomical object.
2. Search MAST for archival observations.
3. Combine results into a research summary.
